# CIVIPIT
<img width="250" height="250" alt="CIVIPIT" src="https://github.com/user-attachments/assets/4063a3de-5f5d-40e6-9628-968856fb6e26" />


CIVIPIT (Commonly Identified Viral Illnesses Predicting Intelligent Tool) is a project application that I oversaw and created for my CS 109, Quantitative Reasoning using Python, course at CWU that guesses the closest probable common viral illness (COVID-19, Norovirus (Stomach flu), Influenza, Common Cold, and Pneumonia) that a user may have depending on their provided answers to prompts.

To visualize prediction data, the matplotlib Python library is utilizied, which allows for graph visualizations based on results. This assists in outputting bar graphs for the program’s score based predictions. Expected outcomes consist of outputting bar graphs that display the closest possible common illness that the user may have depending on provided input and CIVIPIT's point based algorithms. CIVIPIT's expected output’s bar graph’s are displayed from left to right in order of most probable to least probable guessed illness that the user may have, and it relies on pre-made and newly-made datasets that it will utilize for faster output.
